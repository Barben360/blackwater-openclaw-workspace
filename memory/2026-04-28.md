
## Kanban task completion pattern (Ben's vault)

Vault path: `/home/jduff/Workspace/github.com/Barben360/blackwater-services/volumes/obsidian-livesync/vault`
Main tasks board: `Vie Quotidienne/✅ Tâches.md` (kanban, three lanes: TODO, DOING, DONE)

To mark a task as done:
1. Find it: `obsidian-cli search-content "task name"` (always check kanban via `check_kanban.py` first)
2. Remove the `- [ ]` line from its current lane
3. Add `- [x] Task name` under `## DONE` → `**Complete**` (first completed card spot, right after `**Complete**`)
4. Preserve `%% kanban:settings %%` block at end

No fuss, no extra confirmations — just do it.
